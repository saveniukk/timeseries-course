# Лабораторна робота №3

Фільтри alpha-beta та alpha-beta-gamma, адаптація пам'яті фільтра.

## Запуск

1. Python 3.11+ (для ЛР7 потрібен Python 3.11–3.12).
2. `python -m venv .venv`, активувати середовище.
3. `pip install -r requirements.txt`
4. `python main.py`

Вхідні дані лежать у папці `data/`. Повторний парсинг сайту вмикається константою `REFRESH_DATA = True` у `main.py`.
